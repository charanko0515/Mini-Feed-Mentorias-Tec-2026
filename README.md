# Projeto Mini Feed

Projeto prático das Mentorias TEC 2026: uma página no estilo de rede social feita só com HTML e CSS, usando Flexbox, cards, sombras e hover.

## O que tem aqui

| Pasta | Conteúdo |
|---|---|
| [`modelo-1/`](modelo-1/) | Modelo base claro, com roxo de destaque |
| [`modelo-2/`](modelo-2/) | O mesmo HTML do modelo 1 com outro CSS: tema escuro e verde-água |
| [`feed-jojo/`](feed-jojo/) | Exemplo de personalização: um feed de fãs de JoJo's Bizarre Adventure |

Compare o `style.css` do modelo 1 com o do modelo 2: o HTML é igual, só o CSS muda a aparência.

## Como usar

1. Baixe o repositório pelo botão **Code > Download ZIP** e extraia os arquivos.
2. Escolha um modelo e abra o `index.html` no navegador.
3. Edite `index.html` e `style.css` nos pontos marcados com `ALTERE`.
4. Para criar outra postagem, copie um `<article>` inteiro e cole abaixo do anterior.
5. Salve e atualize o navegador a cada mudança.

## Sobre o feed de JoJo

JoJo's Bizarre Adventure é uma obra de Hirohiko Araki. As postagens são de fãs fictícios, e as imagens são ilustrações próprias, sem nenhuma arte oficial.
